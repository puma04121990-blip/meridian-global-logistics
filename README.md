# MERIDIAN — мировая логистика

Браузерная пошаговая экономическая стратегия на русском языке. Без персонажей и фоновых сцен: интерфейс управления всемирной транспортной компанией.

## Запуск

Не требует сборки, npm или внешних зависимостей:

```sh
python3 -m http.server 8080 --directory dist
```

Откройте http://localhost:8080. Прогресс сохраняется локально в браузере под ключом `meridian-save-v1` и не синхронизируется между устройствами или доменами.

## Состав проекта

- `dist/index.html` — страница игры и метаданные.
- `dist/style.css` — адаптивный интерфейс.
- `dist/game.js` — экономическая модель, сохранения и интерфейс.
- `.openai/hosting.json` — конфигурация существующей публикации Sites.

## Механики

Шесть типов транспорта, восемь категорий грузов, пять мировых рынков. Контракты, складские мощности, лицензии, технологии, топливные запасы, износ, ремонт, страхование, задержки, репутация и кредитование. Время движется кнопкой «Завершить день».

Цены и события условные игровые величины. Первая версия; долгосрочный баланс требует дальнейшего тестирования.

## Проверка JavaScript

```sh
node --check dist/game.js
```

## Дальнейшая работа

Основная ветка — `main`. GitHub служит основным репозиторием исходного кода. Перенос исходников сам по себе не включает GitHub Pages и не меняет доступ к существующему сайту.
