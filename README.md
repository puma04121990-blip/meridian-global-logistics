# MERIDIAN — мировая логистика

Браузерная пошаговая экономическая стратегия на русском языке. Без персонажей и фоновых сцен: интерфейс управления всемирной транспортной компанией.

## Запуск

Не требует сборки, npm или внешних зависимостей:

```sh
python3 -m http.server 8080 --directory dist
```

Откройте http://localhost:8080. Прогресс сохраняется локально в браузере под ключом `meridian-save-v1` и не синхронизируется между устройствами или доменами.

## Состав проекта

- `dist/index.html` — страница игры и метаданные.
- `dist/style.css` — адаптивный интерфейс.
- `dist/game.js` — контракты, транспорт, сохранения и интерфейс.
- `dist/economy.js` — товарные рынки, производство, себестоимость и векторная визуализация.
- `tests/economy.test.cjs` — проверки экономических сценариев без зависимостей.
- `.openai/hosting.json` — конфигурация существующей публикации Sites.

## Механики

Шесть типов транспорта, восемь категорий грузов, пять мировых рынков. Контракты, складские мощности, лицензии, технологии, топливные запасы, износ, ремонт, страхование, задержки, репутация и кредитование. Время движется кнопкой «Завершить день».

Версия 2 добавляет четыре торгуемых товара, региональные цены и влияние сделок на спрос, складские запасы, собственные поставки, производство комплектующих и электроники. В себестоимости учитываются закупка, обработка, топливо и сборы. Хранение стоит 2 $/т в день; продукты теряют 3% остатка ежедневно. Заводы требуют оборотных средств и постоянного содержания. Результат торговли показан отдельно от контрактных доходов и общих расходов компании.

Векторные SVG-схемы показывают транспорт, активные рейсы и сеть рынков. Анимация учитывает настройку уменьшения движения. Старые сохранения версии 1 автоматически дополняются новым разделом экономики.

Цены и события условные игровые величины; долгосрочный баланс требует дальнейшего игрового тестирования.

## Проверка JavaScript

```sh
node --check dist/game.js
node --check dist/economy.js
node --test tests/economy.test.cjs
```

## Дальнейшая работа

Основная ветка — `main`. Workflow `.github/workflows/pages.yml` публикует каталог `dist` в GitHub Pages после push в `main` или ручного запуска.

Игра: https://puma04121990-blip.github.io/meridian-global-logistics/

В Settings → Pages источником должен быть выбран GitHub Actions. Сборка и внешние ресурсы игре не требуются.
