# MERIDIAN

- This repository contains the MERIDIAN logistics economy game, not the separate Dog Yard project.
- GitHub is the primary source repository for ongoing work. Use main unless the user requests another branch.
- Preserve the Russian interface and the minimal, character-free visual direction.
- Keep the game runnable as a static site from dist/ without a build step.
- Preserve compatible local saves; introduce explicit migration or version handling for breaking state changes.
- Check JavaScript syntax and exercise economically relevant changes before publishing.
- Never commit credentials, browser saves, tokens or private session data.
- .openai/hosting.json refers to the existing Sites publication; do not create a duplicate Site or change audience without user authorization.
